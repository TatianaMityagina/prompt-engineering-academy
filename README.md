# 🎯 Prompt Engineering Academy

> Интерактивный образовательный портал для изучения промпт-инжиниринга

---

## 🚀 Технологии

- **Vue 3** — компонентный подход, реактивность
- **TypeScript** — типобезопасность
- **Pinia** — управление состоянием (тесты, путешествия, настройки)
- **Vue Router** — навигация
- **Naive UI** — готовые компоненты и тёмная тема
- **Vite** — быстрая сборка
- **canvas-confetti** — праздничные эффекты (XP, достижения)

---

## 🧩 Компоненты упражнений (8 типов)

| Компонент | Назначение |
|-----------|------------|
| `MultipleChoice` | Выбор правильного ответа |
| `TrueFalse` | Верно / Неверно |
| `FillTheBlank` | Заполнение пропусков |
| `MatchPairs` | Соединение пар (термин ↔ определение) |
| `OrderSteps` | Drag-and-drop сортировка шагов |
| `PromptBuilder` | **Кастомный компонент** — сборка промпта из блоков (роль, контекст, задача, формат, ограничения) |
| `CategorySort` | Распределение утверждений по категориям |
| `FreeResponse` | Свободный ответ (используется в путешествиях: объясни просто, перескажи, приведи пример) |

### Архитектура

Все упражнения наследуются от `BaseExercise` — универсальной обертки, которая:
- Управляет состояниями (не отвечено / верно / неверно)
- Показывает обратную связь
- Работает в двух режимах: `inline` (в статье) и `test` (в тесте)
- Проверяет ответы через `deepEqual` (порядок ключей не важен) и поддержку `caseInsensitive`-режима

## 🧭 Knowledge Journey — путешествия по знаниям

Из произвольного учебного текста система строит интерактивное «путешествие по знаниям»: разбивает материал на концепции-чекпоинты, генерирует проверочные активности, добавляет давление времени и геймификацию.

### Возможности

- **Генерация из любого текста**: разбор на концепции (`src/services/engine/textParser.ts`), сборка маршрута (`localGenerator.ts`)
- **Нарратив**: путешествие обрамляется историей (стартап / инцидент / консалтинг / аудит) — `narrative.ts`
- **13 типов активностей**: 6 свободных ответов (объясни просто, перескажи, приведи пример, найди связь, предскажи результат) + 7 закрытых (MultipleChoice, TrueFalse, FillTheBlank, MatchPairs, OrderSteps, PromptBuilder, CategorySort)
- **Давление времени**: на чекпоинт даётся лимит, таймер наращивает напряжение, при истечении — таймаут
- **Геймификация**: XP за правильные ответы, бонус за скорость, множитель за серию стрика, достижения, конфетти
- **Подсказки**: платные подсказки за XP в закрытых упражнениях
- **Финальный отчёт**: разбор по концепциям — что понял, где ошибся, что повторить; скачивание в Markdown и печать

### Генерация

- **Локальный движок** (по умолчанию, без API-ключа) — эвристики: ключевые слова, определения-маркеры, частотность. Генератор следит, чтобы определения не содержали сам термин (прямые подсказки)
- **ИИ-генерация** (опционально): настройки в UI (`AiSettingsModal`), OpenAI-совместимые API (OpenAI, OpenRouter, Ollama, custom). Ключ хранится локально (localStorage), на сервер не отправляется
- Оценка свободных ответов: ИИ или локальный эвристический скоринг

### Архитектура фичи

- `src/services/journeyService.ts` — оркестрация генерации и оценки (ИИ с fallback на локальный движок)
- `src/services/ai/` — провайдер (`provider.ts`), генератор маршрута (`journeyGenerator.ts`), оценка свободных ответов (`evaluator.ts`), промпты (`prompts.ts`)
- `src/services/engine/` — локальные: генератор (`localGenerator.ts`), оценщик (`localEvaluator.ts`), парсер текста (`textParser.ts`), нарратив (`narrative.ts`)
- `src/store/journeyStore.ts` — прогресс, таймер, XP, достижения, персистентность (localStorage)
- Компоненты: `TimerBar`, `CheckpointProgress`, `GamingStrip`, `ActivityView`
- Страницы: `JourneyHomePage` → `JourneyGeneratePage` → `JourneyIntroPage` → `JourneyRunPage` → `JourneyResultPage`
- Роуты: `/journeys`, `/journeys/new`, `/journeys/:id`, `/journeys/:id/run`, `/journeys/:id/result`
