# 🎯 Prompt Engineering Academy

> Интерактивный образовательный портал для изучения промпт-инжиниринга

---

## 🚀 Технологии

- **Vue 3** — компонентный подход, реактивность
- **TypeScript** — типобезопасность
- **Pinia** — управление состоянием (тесты, путешествия, настройки)
- **Vue Router** — навигация
- **Naive UI** — готовые компоненты и тёмная тема
- **Vite** — быстрая сборка
- **canvas-confetti** — праздничные эффекты (XP, достижения)
- **RAG без бэкенда** — собственный BM25 с русским стеммингом + опциональные эмбеддинги (OpenAI-совместимый `/embeddings`), слияние через Reciprocal Rank Fusion
- **LLM** — любой OpenAI-совместимый API (OpenAI, OpenRouter, Ollama, свой сервер); ключ хранится только в браузере

## 🧩 Компоненты упражнений (8 типов)

| Компонент | Назначение |
|-----------|------------|
| `MultipleChoice` | Выбор правильного ответа |
| `TrueFalse` | Верно / Неверно |
| `FillTheBlank` | Заполнение пропусков |
| `MatchPairs` | Соединение пар (термин ↔ определение) |
| `OrderSteps` | Drag-and-drop сортировка шагов |
| `PromptBuilder` | **Кастомный компонент** — сборка промпта из блоков (роль, контекст, задача, формат, ограничения) |
| `CategorySort` | Распределение утверждений по категориям |
| `FreeResponse` | Свободный ответ (используется в путешествиях: объясни просто, перескажи, приведи пример) |

### Архитектура

Все упражнения наследуются от `BaseExercise` — универсальной обертки, которая:
- Управляет состояниями (не отвечено / верно / неверно)
- Показывает обратную связь
- Работает в двух режимах: `inline` (в статье) и `test` (в тесте)
- Проверяет ответы через `deepEqual` (порядок ключей не важен) и поддержку `caseInsensitive`-режима

## 🧭 Knowledge Journey — путешествия по знаниям

Из произвольного учебного текста система строит интерактивное «путешествие по знаниям»: разбивает материал на концепции-чекпоинты, генерирует проверочные активности, добавляет давление времени и геймификацию.

### Возможности

- **Генерация из любого текста**: разбор на концепции (`src/services/engine/textParser.ts`), сборка маршрута (`localGenerator.ts`)
- **Нарратив**: путешествие обрамляется историей (стартап / инцидент / консалтинг / аудит) — `narrative.ts`
- **13 типов активностей**: 6 свободных ответов (объясни просто, перескажи, приведи пример, найди связь, предскажи результат) + 7 закрытых (MultipleChoice, TrueFalse, FillTheBlank, MatchPairs, OrderSteps, PromptBuilder, CategorySort)
- **Давление времени**: на чекпоинт даётся лимит, таймер наращивает напряжение, при истечении — таймаут
- **Геймификация**: XP за правильные ответы, бонус за скорость, множитель за серию стрика, достижения, конфетти
- **Подсказки**: платные подсказки за XP в закрытых упражнениях
- **Финальный отчёт**: разбор по концепциям — что понял, где ошибся, что повторить; скачивание в Markdown и печать

### Генерация

- **Локальный движок** (по умолчанию, без API-ключа) — эвристики: ключевые слова, определения-маркеры, частотность. Генератор следит, чтобы определения не содержали сам термин (прямые подсказки)
- **ИИ-генерация** (опционально): настройки в UI (`AiSettingsModal`), OpenAI-совместимые API (OpenAI, OpenRouter, Ollama, custom). Ключ хранится локально (localStorage), на сервер не отправляется
- Оценка свободных ответов: ИИ или локальный эвристический скоринг

### Архитектура фичи

- `src/services/journeyService.ts` — оркестрация генерации и оценки (ИИ с fallback на локальный движок)
- `src/services/ai/` — провайдер (`provider.ts`), генератор маршрута (`journeyGenerator.ts`), оценка свободных ответов (`evaluator.ts`), промпты (`prompts.ts`)
- `src/services/engine/` — локальные: генератор (`localGenerator.ts`), оценщик (`localEvaluator.ts`), парсер текста (`textParser.ts`), нарратив (`narrative.ts`)
- `src/store/journeyStore.ts` — прогресс, таймер, XP, достижения, персистентность (localStorage)
- Компоненты: `TimerBar`, `CheckpointProgress`, `GamingStrip`, `ActivityView`
- Страницы: `JourneyHomePage` → `JourneyGeneratePage` → `JourneyIntroPage` → `JourneyRunPage` → `JourneyResultPage`
- Роуты: `/journeys`, `/journeys/new`, `/journeys/:id`, `/journeys/:id/run`, `/journeys/:id/result`

## 🤖 ИИ-расширение (Модуль 4B)

Платформа превратилась из «библиотеки без библиотекаря» в обучающую систему: ищет по своим материалам
с источниками, выполняет ИИ-действия и помнит прогресс студента. Ход работы, решения и промпт-журнал
описаны в [`DEV_NOTES.md`](./DEV_NOTES.md).

### RAG по контенту

| Что индексируется | Как режется | Куда ведёт источник |
|---|---|---|
| Статьи | По секциям (заголовок-строка капсом), длинные — по абзацам ≤ 700 символов | `/article/:slug#sec-N` с подсветкой секции |
| Упражнения статей | Отдельный чанк «вопрос → правильный ответ → пояснение» | Секция статьи с упражнением |
| Journey | Чекпоинт (концепция + цитата) и каждая активность как «вопрос → ответ» | `/journeys/:id` |
| ИИ-заметки | Одна заметка — один чанк, помечен `🤖 ИИ` | Материал, к которому заметка относится |

- **Поиск:** BM25 работает всегда (без сети). Если в настройках указана модель эмбеддингов, добавляется
  семантический поиск, а результаты сливаются через RRF.
- **Обновление индекса:** индекс — `computed` от статей, Journey и заметок, поэтому пересобирается сам.
  Векторы кэшируются по хэшу содержимого и досчитываются только для новых чанков.
- **Ответ:** LLM отвечает **только по найденным фрагментам** и ставит ссылки `[n]`. Ссылки кликабельны
  и подсвечивают карточку источника. Несуществующие номера вырезаются. Если ничего не найдено,
  ассистент честно говорит, что в материалах этого нет.
- **Код:** `src/services/rag/` (sections, indexer, tokenize, bm25, embeddings, retriever), `src/store/ragStore.ts`.

### ИИ-функции (не чат)

| Действие | Где | Что делает | Без ключа |
|---|---|---|---|
| 💡 **Объясни проще** | Под каждой секцией статьи; в отчёте Journey у тем < 70% | Коротко / аналогия / пример / *твоя* частая ошибка / вопрос для самопроверки, со ссылками на источники | Сжатая выжимка + вопрос из упражнения |
| 🧠 **Где мои слабые места и что дальше?** | `/progress` | Анализирует ответы и ошибки, объясняет причины, строит план с проверенными ссылками | Правила по статистике |
| 🎯 **Тренировка по слабым темам** | `/progress`, кнопка в отчёте Journey | Собирает текст по выбранным темам из RAG-индекса и генерирует новый Journey | Локальный генератор Journey |
| 🔎 Ассистент по материалам | Шапка, `Ctrl/⌘+K`, статья, главная | Ответ на вопрос с источниками; кнопка «🔗 Связи с другими темами» | Ближайшие фрагменты |

Код: `src/services/ai/actions.ts`, промпты — `src/services/ai/prompts.ts`, оркестрация — `src/composables/useAiActions.ts`.

### Персонализация

- **Что хранится** (`src/store/learnerStore.ts`, localStorage): каждая попытка ответа (статья, тест, Journey)
  с темой и текстом вопроса, время чтения статей (только пока вкладка видима), ИИ-заметки, последний анализ.
- **Освоение темы:** по последним 10 попыткам со сглаживанием `(верно + 1) / (попыток + 2)`.
- **Без переполнения контекста:** в промпт уходит не история, а сводка с бюджетом ~900 символов,
  собранная по приоритету: итоги → слабые темы → недавние ошибки → сильные темы.
  Для «Объясни проще» передаётся только история по этой теме.
- **Где видно:** «Что изучить дальше» на главной, отметки «✓ прочитано», карта освоения тем на `/progress`,
  персональные подсказки в ассистенте.
- **Контроль данных:** переключатель «Учитывать мой прогресс в ИИ-ответах», превью «Что ИИ узнаёт обо мне»
  (ровно та строка, что уходит в модель), экспорт JSON, сброс статистики, полное удаление.

### Человек vs ИИ

Везде используется бейдж `👤 Автор курса` / `🤖 ИИ` / `⚙️ Авто`. ИИ-ответы оформлены пунктирной рамкой
и подписаны моделью. В промпте у источников указан автор, и модели велено при противоречии
доверять человеку. Сгенерированные тренировки сохраняются в «Моих путешествиях» с тегом «ИИ» или «Локально».

### Как попробовать

1. `npm install && npm run dev` → открыть http://localhost:5173
2. **Без ключа:** нажать `Ctrl/⌘+K` и спросить «что я знаю о галлюцинациях?». Появятся фрагменты
   со ссылками на секции статей. Клик по источнику откроет нужную секцию.
3. **Подключить ИИ:** ⚙️ ИИ в шапке → провайдер (например, OpenRouter), ключ, модель
   (`openai/gpt-4o-mini`), эмбеддинги (`openai/text-embedding-3-small`; пусто — только BM25) →
   «Проверить соединение» → «Сохранить».
4. Открыть статью → решить упражнения (лучше пару неправильно) → «💡 Объясни проще» под секцией.
5. Пройти тест по статье → **📈 Прогресс** → «Проанализировать» → отметить слабые темы →
   «✨ Сгенерировать тренировку» → пройти новый Journey.
6. Сохранить объяснение в заметки → спросить ассистента о той же теме: заметка появится в источниках с бейджем 🤖.
